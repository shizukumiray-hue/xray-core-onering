TECHNICAL NOTES
================================================================================

BUG #3 (Provider Selection Inconsistency) - Design Decision:
- Cache is per-connection, not global
- Config struct is created per-connection in Xray-core
- Cache lifetime matches connection lifetime
- First call to selectProviderOnce() selects and caches
- Subsequent calls (GetDialAddress, GetTLSSNI) return cached value
- Ensures dial address and TLS SNI use same provider

BUG #5 (Provider Mutation Race) - Design Decision:
- Transport layer no longer directly mutates provider state
- All mutations go through MultiCDNManager synchronized methods
- Manager holds lock during provider lookup + mutation
- Health check loop also uses same lock
- No race possible between transport and health check
